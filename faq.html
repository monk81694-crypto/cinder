Online-mode servers verify sessions with Mojang. Offline names fail. Use Microsoft login.

Fabric and Quilt install automatically. Forge and NeoForge mods trigger a mismatch warning.

Cinder is free to download. Minecraft itself requires a paid Java account for online-mode servers.

Default game folder: %AppData%/.cinder-minecraft. It is portable and changeable in Settings.

Cinder checks GitHub releases on launch. You can also check from Settings.

Installed versions launch offline. Installing versions, Modrinth and Microsoft login need a connection.

Keep the Discord desktop app open. No bot or setup. Your profile shows Playing Cinder, then your version and server in game.

Modrinth search covers individual mods. Modpack import is not listed in v2.0.0.

Cinder has no analytics service. It contacts Mojang, Modrinth, Minotar and GitHub for the features above. Copy diagnostics is manual.
