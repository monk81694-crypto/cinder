Frequently asked questions

Can I play with an offline account (no Microsoft login)?

Yes. Cinder supports offline profiles, including the built-in name forge that generates valid 3–16 character names. Offline names work on offline-mode servers, LAN worlds, and self-hosted servers with online-mode=false.

Does Microsoft login work for premium servers like Hypixel?

Yes. Sign in with a Microsoft account that owns Minecraft Java to join any server, including online-mode premium servers such as Hypixel. The token auto-refreshes on launch.

Which mod loaders are supported?

Fabric and Quilt are auto-installed by the launcher. Forge and NeoForge show mismatch warnings, so they need manual setup.

Is Cinder free?

Yes, Cinder itself is free to download. © 2026 radoslavgeme. All rights reserved — Cinder is proprietary software, not open source. Note that Minecraft Java itself requires a paid account for online-mode servers.

Where are my files stored?

In a portable game directory, by default %AppData%/.cinder-minecraft (changeable in Settings). Saves live in <gameDir>/saves and backups in <gameDir>/backups.

How do I update Cinder?

Cinder checks GitHub releases on launch (toggle in Settings → Performance and updates) with a Check now button. Download the newest installer from the Download page — your worlds, mods and settings live in the portable game directory, not in the installer.

Does Cinder work offline?

Mostly yes: singleplayer, LAN, and offline-mode servers work, and the version list has an offline fallback. You cannot join online-mode servers with an offline name — they reject it with “Invalid session”.

What Java version do I need?

Usually none to install yourself — Cinder auto-detects installed Javas and picks per version (26.x to Java 25, 1.20.5 / 1.21+ to Java 21, 1.18+ to Java 17). You can override it in the Settings Java dropdown.
