Everything in one launcher.

Eleven tabs: Play, Servers, Versions, Profiles, Skins, Worlds, Mods, Resource Packs, Shader Packs, Settings, Logs.

Accounts, groups & Microsoft login.

Offline profiles with name forge, Microsoft login with Xbox gamertag, and profile groups (Survival, Creative, Modded, Testing).

  • Microsoft token refreshes on launch; Xbox profile pic + gamertag shown
  • Name forge: five styles + Custom pattern (regex), always 3-16 valid chars
  • Duplicate names blocked; click avatar to switch; drag-to-reorder in groups
  • Profile groups with per-group default version/loader/server

Any Minecraft version, the right Java.

Live Mojang list with filters, vendor detection, and one-click JDK install.

  • Release, snapshot, beta, alpha filters; installed badges + installed-only
  • Java picked per version: 1.18+→17, 1.20.5+→21, 26.x→25
  • Vendor badges: Temurin, Microsoft, Oracle, Azul Zulu, BellSoft, Adoptium, GraalVM
  • Architecture (x64/arm64) + FX support; "Install recommended Java" button (Eclipse Temurin LTS)
  • Cached 6 hours with offline fallback

Modrinth mods, auto-updates, dependency graph.

Search, install, manage — Fabric/Quilt auto-install, Forge/NeoForge mismatch warnings.

  • Modrinth project page: changelog, dependencies, versions table, screenshots, version picker
  • Auto-update check (daily/weekly/never); "Update all" or per-mod; pinned versions respected
  • Dependency graph toggle (tree view); compatibility warnings before download
  • Profile-specific mods folder; enable/disable persists across restarts

Resource packs — Vanilla Tweaks catalog.

Drag & drop .zip packs, enable/disable per profile, auto-sort by priority, live pack.mcmeta preview.

  • Vanilla Tweaks catalog: fetch list, one-click install popular packs
  • Drag-to-reorder priority; per-profile enable/disable
  • Live preview of pack.mcmeta (description, format, supported versions)
  • Open resource packs folder from the app

Shader packs — Iris & OptiFine.

Add .zip shader packs, toggle per profile, screenshot preview, auto-detect Iris vs OptiFine.

  • Per-profile shader toggle; preview screenshot before enabling
  • Auto-detects Iris (Fabric) vs OptiFine (Forge) and warns if mismatched
  • Open shaders folder from the app

Server groups & region-aware ping.

Organize into groups (Favorites, Minigames, SMP, Anarchy), region ping badges (US/EU/AS).

  • Groups: collapsible, drag reorder, custom server saves to group
  • Region-aware ping: colored latency badges (🇺🇸 US, 🇪🇺 EU, 🇸🇬 AS)
  • Copy IP button per card; live players, MOTD, version; 60s cache
  • Fast Rust probe (slp-probe) with pure-Node fallback

Launch profiles — named configs per profile.

Save multiple setups (version, loader, mods, resource packs, shaders, JVM args, memory, resolution). Switch instantly from Play tab.

  • Per-account launch profiles: "Modded 1.21.4 + Shaders", "Vanilla 1.20.4 + Sodium", etc.
  • Launch button splits: "Launch" / "Launch with profile…" submenu
  • Includes: version, loader, mods, resource packs, shader packs, JVM args, memory, resolution, server

Worlds — backup, restore, health check.

Singleplayer saves with size/date, zip backup, restore (keeps .bak), delete with confirm.

  • Backup to /backups/-YYYYMMDD-HHMM.zip
  • Restore newest backup; current folder kept as .bak-
  • Game directory health check: scans for corrupted jars, missing libs, orphaned mods, duplicate packs, invalid symlinks — report + auto-fix

Performance, Discord, import/export.

JVM presets, RAM sliders, per-profile Discord status, MultiMC import, settings export/import, game dir health check.

  • JVM presets: balanced, performance (G1GC), latency (ZGC, Java 21+); RAM sliders, resolution, custom JVM args
  • Discord: per-profile custom status ("Playing Cinder · Modded 1.21"), reconnects within 5s on wake
  • MultiMC/Prism/ATLauncher instance import: copies versions, mods, configs, packs, shaders, Java settings
  • Export/import settings JSON (encrypted accounts, versioned schema, migrates everything)
  • Game dir health check: corrupted jars, missing libs, orphaned mods, duplicate packs, invalid symlinks
  • High-contrast mode toggle; full keyboard nav; ARIA live regions; focus trap in modals
