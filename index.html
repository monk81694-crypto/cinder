What you get

Accounts & Groups

Offline profiles, Microsoft login, Xbox gamertag, profile groups (Survival, Creative, Modded, Testing) with per-group defaults.

Versions & Java

Live Mojang list. Auto Java per version. Vendor detection (Temurin, Microsoft, Azul, BellSoft). One-click JDK install.

Mods + Packs + Shaders

Modrinth search and install. Resource packs (Vanilla Tweaks catalog). Shader packs (Iris/OptiFine). Auto mod updates.

Servers

Server groups, region-aware ping (US/EU/AS), live player counts. Copy IP, quick-join per group.

Launch Profiles

Named configs per profile: version, loader, mods, resource packs, shaders, JVM args, memory, resolution. Switch instantly.

Discord + More

Per-profile Discord status. MultiMC import. Settings export/import. Game dir health check. High contrast mode.
