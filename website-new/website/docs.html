Install

A. Installer

Download the .exe, .dmg or AppImage from the download page and run it.

B. From source

cd tlauncher
npm install
npm start

First launch

Add an account, pick a version and press Launch (Ctrl+Enter). The first launch downloads the game version, about 200 MB.

Versions

Search the Mojang list and filter by release, snapshot, beta or alpha. Installed versions are badged and can be uninstalled.

Mods

Search Modrinth, choose a version and install. Choosing Fabric or Quilt installs the loader automatically. Toggle installed mods on or off in the local list.

Worlds

Backup writes a zip to <gameDir>/backups. Restore extracts the newest backup and keeps your current folder as .bak-<timestamp>.

Skins

Preview a username, load your profile skin or upload a 64x64 PNG.

Troubleshooting

Failed to log in: Invalid session

You are using an offline name on an online-mode server. Sign in with Microsoft. No launcher can bypass this.

Java not found or wrong version

Open Settings and pick a Java from the dropdown. Cinder picks 17, 21 or 25 per version when it can find them.

Discord shows Minecraft, not Cinder

Open the Discord desktop app before launching. In Cinder, Settings > Discord > Test should say Connected. If not, remove the Minecraft entry under Discord Registered Games and restart Discord.

Updates

Use Settings > Check for updates, or download the latest installer from the download page.
