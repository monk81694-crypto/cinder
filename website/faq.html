Frequently Asked Questions

Short factual answers for Cinder v2.0.0. Can't find what you need? Check Docs or GitHub Issues.

Can I play with an offline account (no Microsoft login)?

Yes. Cinder supports offline profiles, including the built-in name forge that generates valid 3–16 character names. Offline names work on offline-mode servers, LAN worlds, and self-hosted servers with online-mode=false.

Does Microsoft login work for premium servers like Hypixel?

Yes. Sign in with a Microsoft account that owns Minecraft Java to join any server, including online-mode premium servers such as Hypixel. The token auto-refreshes on launch.

Which mod loaders are supported?

Fabric and Quilt are auto-installed by the launcher. Forge and NeoForge show mismatch warnings, so they need manual setup.

Is Cinder free?

Yes, Cinder itself is free to download. © 2026 radoslavgeme. All rights reserved — Cinder is proprietary software, not open source. Note that Minecraft Java itself requires a paid account for online-mode servers.

Where are my files stored?

In a portable game directory, by default %AppData%/.cinder-minecraft (changeable in Settings). Saves live in /saves and backups in /backups.

How do I update Cinder?

Cinder checks GitHub releases on launch (toggle in Settings → Performance and updates) with a Check now button. Download the newest installer from the Download page — your worlds, mods and settings live in the portable game directory, not in the installer.

Does Cinder work offline?

Mostly yes: singleplayer, LAN, and offline-mode servers work, and the version list has an offline fallback. You cannot join online-mode servers with an offline name — they reject it with "Invalid session".

What Java version do I need?

Usually none to install yourself — Cinder auto-detects installed Javas and picks per version (26.x to Java 25, 1.20.5 / 1.21+ to Java 21, 1.18+ to Java 17). You can override it in the Settings Java dropdown.

Why does my Discord status show "Minecraft" instead of "Cinder"?

Discord has built-in game detection for javaw.exe that shows a generic Minecraft status. Cinder's Rich Presence replaces it — but only while connected. Checklist: Discord desktop app open before launching → Settings → Discord → Test says Connected ✓. Still losing? Discord → Settings → Registered Games → remove the Minecraft entry → restart Discord → Test again. Cinder also retries the connection every 30s on its own.

Can I use Cinder on a server that requires a specific modpack?

Yes. Install the required mods via the Mods tab (Modrinth search or custom .jar), pick the matching loader (Fabric/Quilt auto-install), and launch. For Forge/NeoForge modpacks, you'll need to install the loader manually into the game directory first.

How do I back up my worlds?

Go to the Worlds tab → click Backup on any world. It creates a zip in /backups/-YYYYMMDD-HHMM.zip. To restore, click Restore — the current world is kept as a timestamped .bak copy before the backup is extracted.

Does Cinder collect any data or telemetry?

No. Cinder has no telemetry, no analytics, no crash reporting, and no phone-home except for checking GitHub releases (toggleable in Settings). All network requests are user-initiated: version list, Modrinth search, skin fetch, server ping, Microsoft login, Discord presence.

Still stuck? See Docs → Troubleshooting or open an issue on GitHub.
