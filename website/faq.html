Fabric and Quilt install automatically. Forge and NeoForge mods trigger a mismatch warning.

Resource packs change textures/models/sounds. Drag & drop .zip, enable per profile, Vanilla Tweaks catalog one-click install.
Shader packs add lighting/shadows. Iris (Fabric) and OptiFine (Forge) supported. Toggle per profile with preview.

Named configs per account: version, loader, mods, resource packs, shaders, JVM args, memory, resolution, server. Switch instantly from Play tab dropdown. Examples: "Modded 1.21.4 + Shaders", "Vanilla 1.20.4 + Sodium".

Cinder is free to download. Minecraft itself requires a paid Java account for online-mode servers.

Default game folder: %AppData%/.cinder-minecraft. It is portable and changeable in Settings.

Cinder checks GitHub releases on launch. You can also check from Settings. Modrinth mod auto-updates configurable (daily/weekly/never).

Installed versions launch offline. Installing versions, Modrinth, Microsoft login need a connection.

Keep the Discord desktop app open. No bot or setup. Your profile shows Playing Cinder (or your custom per-profile status), then your version and server in game. Reconnects within 5s on wake.

Modrinth search covers individual mods. MultiMC/Prism/ATLauncher instance import brings versions, mods, configs, packs, shaders, Java settings.

Cinder has no analytics service. It contacts Mojang, Modrinth, Minotar and GitHub for features. Copy diagnostics is manual and sanitizes paths (replaces home with ~).

Settings > Import > select MultiMC/Prism/ATLauncher instance folder. Copies versions, mods, configs, resource packs, shader packs, Java settings.

Settings > Export > saves encrypted JSON. Import on new machine restores accounts, versions, mods, packs, shaders, JVM, servers, Discord config.

Settings > Verify game dir scans for corrupted jars, missing libraries, orphaned mods, duplicate resource packs, invalid symlinks. Shows report + auto-fix button.

Settings > Java > "Install recommended Java" downloads Eclipse Temurin LTS matching your version, extracts to game dir, auto-selects it.

Organize servers into groups (Favorites, Minigames, SMP, Anarchy). Ping shows region flags (🇺🇸 US, 🇪🇺 EU, 🇸🇬 AS) with colored latency badges. Custom server saves to chosen group.
