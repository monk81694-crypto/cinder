Install

Option A — installer (most players): grab the build for your system on the Download page — Windows installer (.exe), macOS disk image (.dmg), or Linux AppImage — and run it.

Option B — run from source:

cd tlauncher
npm install
npm start

Extras: npm run dev opens devtools, npm run typecheck runs tsc --noEmit, npm test runs the checks, and npm run dist builds distributable installers (Windows NSIS / macOS dmg / Linux AppImage).

First launch

  • First launch downloads the game version (about 200 MB).
  • Java is auto-detected and auto-picked per version: 26.x goes to Java 25, 1.20.5 / 1.21 and newer go to Java 21, 1.18 and newer go to Java 17.
  • Add an account (offline name or Microsoft login), pick a version, optionally type a server IP for quick-join, then LAUNCH. The launcher remembers your last account, version and server.

Versions

The Versions tab shows the live Mojang version list (cached 6 hours, with an offline fallback), with search, release / snapshot / beta / alpha filters, installed badges plus an installed-only filter, and uninstall for versions you no longer need.

Mods

  • Browse and install from Modrinth search with a version picker.
  • Your local list has an enable / disable toggle per mod.
  • Fabric and Quilt loaders auto-install; Forge and NeoForge show mismatch warnings, so they need manual setup.

Worlds and backups

  • The Worlds tab lists singleplayer saves found in <gameDir>/saves (folders containing level.dat), with size and modified date, Refresh, and Open saves folder.
  • Backup zips a world to <gameDir>/backups/<name>-YYYYMMDD-HHMM.zip.
  • Restore extracts the newest backup for that world; the current folder is kept as .bak-<timestamp>.
  • Delete removes the save folder after a confirm modal.

Skins

  • The Skins tab shows a live 3D preview (skinview3d, auto-spin and walking pose, zoom locked).
  • Try a name: type any Java username to fetch its live skin (24 h disk cache).
  • My profile skin loads the active account skin in one click; Upload PNG imports a classic 64x64 PNG from disk; Save PNG downloads the current preview frame.

Troubleshooting

Offline vs online-mode servers (“Invalid session”)

Offline names work on offline-mode servers, LAN worlds, and self-hosted servers with online-mode=false. They can never join online-mode premium servers such as Hypixel: those servers ask Mojang whether the session is valid and reject anything unsigned with “Failed to log in: Invalid session”. Sign in with a Microsoft account that owns Minecraft Java for those servers; the token auto-refreshes on launch.

Java issues

Cinder detects Java generically (JAVA_HOME, PATH, Adoptium, Microsoft, Temurin, BellSoft, Zulu builds, and Mojang-bundled runtimes — no hardcoded paths) and auto-picks per version (26.x to Java 25, 1.20.5 / 1.21+ to Java 21, 1.18+ to Java 17). If the wrong runtime is used, switch it in the Settings Java dropdown.

Discord status

Keep the Discord desktop app open before launching: your profile shows “Playing Cinder” with the logo, switching to “Playing Minecraft {version}” in game. If Settings → Discord → Test does not say Connected, or your profile shows the generic Minecraft grass block, open Discord → Settings → Registered Games, remove the Minecraft entry, restart Discord and Test again. The launcher also retries the connection every 30 s on its own.

Updates and diagnostics

Settings → Performance and updates: JVM presets balanced (default), performance, latency (ZGC, Java 21+ only); snowfall toggle; Check for updates with a Check now button; Copy diagnostics (version, Java list, settings, Mojang / Modrinth / Minotar reachability plus log tail) for support.
