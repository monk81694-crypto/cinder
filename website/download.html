System requirements

  • Windows 10 or newer (installer .exe), macOS (.dmg), or Linux (AppImage).
  • Java: auto-detected — no manual install needed for most players. Cinder picks per version: Minecraft 26.x goes to Java 25, 1.20.5 / 1.21 and newer go to Java 21, 1.18 and newer go to Java 17.
  • Disk and network: about 200 MB downloads on first launch for the game version. Game files live in a portable folder (default %AppData%/.cinder-minecraft).
  • Node.js: not needed — end users just run the installer. Node and npm install are only for building from source (see Docs).
  • Accounts: play offline on offline-mode servers, or sign in with Microsoft (owns Minecraft Java) for online-mode servers such as Hypixel.
