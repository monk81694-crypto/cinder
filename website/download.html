System Requirements

Windows

Windows 10 or newer (installer .exe)

macOS

macOS 11+ (disk image .dmg)

Linux

Any distro with FUSE (AppImage)

Java

Auto-detected — no manual install needed. Cinder picks per version: 26.x → Java 25, 1.20.5+/1.21+ → Java 21, 1.18+ → Java 17.

Disk & Network

~200 MB downloads on first launch for the game version. Game files in portable folder (default %AppData%/.cinder-minecraft).

Accounts

Play offline on offline-mode servers, or sign in with Microsoft (owns Minecraft Java) for online-mode servers like Hypixel.
