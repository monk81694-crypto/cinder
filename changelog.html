Changelog

2.0.1

2026-11-16

Added

  • Resource Packs tab — drag & drop .zip packs, enable/disable per profile, auto-sort by priority, live pack.mcmeta preview, Vanilla Tweaks catalog (one-click install).
  • Shader Packs tab — Iris/OptiFine shader management, add .zip packs, toggle per profile, screenshot preview, auto-detect Iris vs OptiFine.
  • MultiMC/Prism/ATLauncher instance import — copies versions, mods, configs, resource packs, shaders, Java settings.
  • Profile grouping — organize accounts into groups (Survival, Creative, Modded, Testing), collapsible sidebar, drag-to-reorder, per-group defaults.
  • Launch profiles — named launch configs per profile (version, loader, mods, resource packs, shaders, JVM args, memory, resolution), dropdown on Play tab.
  • Modrinth project page — in-app detail view with changelog, dependencies, versions table, screenshots, version picker.
  • Auto-update mods — background Modrinth update check, badge on Mods tab, "Update all" / per-mod, pinned versions, configurable interval.
  • Server groups & ping regions — groups (Favorites, Minigames, SMP, Anarchy), region-aware ping (US/EU/AS) with colored latency badges.
  • Discord RPC per-profile status — custom status text per account ("Playing Cinder · Modded 1.21"), set in profile editor.
  • Java vendor detection UI — vendor badge (Temurin, Microsoft, Oracle, Azul, BellSoft, Adoptium, GraalVM) + arch + FX support, mismatch warnings.
  • JDK download helper — "Install recommended Java" button, downloads Eclipse Temurin LTS via Adoptium API, extracts to game dir, auto-selects.
  • Game directory health check — scans for corrupted jars, missing libs, orphaned mods, duplicate packs, invalid symlinks; report + auto-fix.
  • Export/import settings — JSON config with encrypted accounts, versioned schema, migrates accounts/versions/mods/packs/shaders/JVM/servers/Discord.
  • Command palette enhancements — searches mods, packs, shaders, servers, settings, accounts; fuzzy match, keyboard nav, recent items.
  • Accessibility — full keyboard nav, ARIA live regions, high-contrast mode toggle, screen-reader labels, focus trap in modals.

Changed

  • Version bumped to 2.0.1 across package.json, index.html, README, website.
  • Play tab redesign — instance pill shows launch profile dropdown; larger skin canvas; server quick-join group chips; launch button splits to "Launch" / "Launch with profile…".
  • Accounts tab — profile group sidebar; Microsoft login shows Xbox gamertag + pic; offline name generator adds "Custom pattern" (regex) style.
  • Mods tab — dependency graph toggle (tree view); compatibility warnings before download; profile-specific mods folder.
  • Servers tab — group chips above grid; ping column shows region flag (🇺🇸🇪🇺🇸🇬); "Copy IP" per card; custom server saves to group.
  • Settings — reorganized sections (Game, Java, Performance, Appearance, Discord, Advanced); search filter; JVM preset cards with descriptions.
  • Logs — level filter pills, "Copy last 100 lines", timestamp toggle, "Save to file".
  • Website — all 6 pages updated with 2.0.1 features; new screenshots for Resource Packs, Shader Packs, Profiles, Launch Profiles.

Fixed

  • Microsoft token refresh race condition on rapid relaunch.
  • Modrinth version picker showing incompatible loaders for Fabric/Quilt.
  • World backup timestamp collision on rapid successive backups.
  • Discord RPC disconnect on sleep/wake (reconnects within 5s).
  • Java auto-detect picking wrong architecture on arm64 macOS.
  • Mod enable/disable not persisting across launcher restarts.
  • Command palette not closing on ESC in some cases.
  • High-contrast mode not applying to custom scrollbars.

Security

  • Account encryption: offline UUIDs encrypted at rest (AES-256-GCM, key from machine ID + optional password).
  • Modrinth API calls use pinned TLS certificates (certificate pinning).
  • Diagnostic copy sanitizes file paths (replaces user home with ~).
