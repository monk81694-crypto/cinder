Install

A. Installer

Download the .exe, .dmg or AppImage from the download page and run it.

B. From source

cd tlauncher
npm install
npm start

First launch

Add an account, pick a version and press Launch (Ctrl+Enter). The first launch downloads the game version, about 200 MB.

Versions

Search the Mojang list and filter by release, snapshot, beta or alpha. Installed versions are badged and can be uninstalled.

Java is auto-picked per version: 1.18+ uses 17, 1.20.5+ uses 21, 26.x uses 25. Vendor badges show Temurin, Microsoft, Oracle, Azul, BellSoft, Adoptium, GraalVM. Use "Install recommended Java" for one-click Eclipse Temurin LTS install.

Accounts & Groups

Add offline profiles (name forge: Mixed, Ember, Hero, Dark, Cute, Custom regex) or sign in with Microsoft (shows Xbox gamertag + profile pic).

Organize into groups: Survival, Creative, Modded, Testing (or custom). Groups are collapsible in the sidebar, drag-to-reorder, with per-group default version/loader/server.

Mods

Search Modrinth, pick a version and install. Fabric/Quilt install automatically. Forge/NeoForge mods show mismatch warnings.

  • Modrinth project page: changelog, dependencies, versions table, screenshots, version picker
  • Auto-update check (daily/weekly/never); "Update all" or per-mod; pinned versions respected
  • Dependency graph toggle (tree view); compatibility warnings before download
  • Profile-specific mods folder; enable/disable persists across restarts

Resource Packs

Drag & drop .zip packs, enable/disable per profile, auto-sort by priority, live pack.mcmeta preview.

  • Vanilla Tweaks catalog: fetch list, one-click install popular packs
  • Drag-to-reorder priority; per-profile enable/disable
  • Open resource packs folder from the app

Shader Packs

Add .zip shader packs, toggle per profile, screenshot preview, auto-detect Iris vs OptiFine.

  • Per-profile shader toggle; preview screenshot before enabling
  • Auto-detects Iris (Fabric) vs OptiFine (Forge) and warns if mismatched
  • Open shaders folder from the app

Servers

Organize into groups (Favorites, Minigames, SMP, Anarchy, custom). Region-aware ping (US/EU/AS) with colored latency badges.

  • Groups: collapsible, drag reorder, custom server saves to group
  • Copy IP button per card; live players, MOTD, version; 60s cache
  • Fast Rust probe (slp-probe) with pure-Node fallback

Launch Profiles

Named configs per account: version, loader, mods, resource packs, shader packs, JVM args, memory, resolution, server. Switch instantly from Play tab dropdown.

Launch button splits: "Launch" (uses active profile) / "Launch with profile…" (submenu).

Worlds

Singleplayer saves with size/date. Backup writes zip to /backups/-YYYYMMDD-HHMM.zip. Restore extracts newest backup; current folder kept as .bak-.

Game directory health check: scans for corrupted jars, missing libs, orphaned mods, duplicate packs, invalid symlinks — report + auto-fix.

Performance & Discord

JVM presets: balanced, performance (G1GC), latency (ZGC, Java 21+). RAM sliders, resolution presets, custom JVM args.

Discord: per-profile custom status ("Playing Cinder · Modded 1.21"), reconnects within 5s on wake. No bot/token/setup for players.

Import / Export

MultiMC/Prism/ATLauncher import: copies versions, mods, configs, packs, shaders, Java settings.

Export settings: JSON with encrypted accounts, versioned schema, migrates accounts/versions/mods/packs/shaders/JVM/servers/Discord.

Import settings: restores full config on new machine or after reinstall.

Troubleshooting

Failed to log in: Invalid session

You are using an offline name on an online-mode server. Sign in with Microsoft. No launcher can bypass this.

Java not found or wrong version

Open Settings and pick a Java from the dropdown. Cinder picks 17, 21 or 25 per version when it can find them. Use "Install recommended Java" for Temurin LTS.

Discord shows Minecraft, not Cinder

Open Discord desktop app before launching. Settings > Discord > Test should say Connected. If not, remove Minecraft entry under Discord Registered Games and restart Discord.

Mod enable/disable not persisting

Fixed in 2.0.1. If still happening, check Mods tab > profile-specific mods folder is writable.

Discord RPC disconnect on sleep/wake

Fixed in 2.0.1 — reconnects within 5s automatically.

Updates

Settings > Check for updates, or download latest installer from the download page.
